# Сайт кав'ярні з інтегрованою системою знижок за дисконтною картою

Кваліфікаційна робота на підтвердження ступеня фахового молодшого бакалавра ([ВСП «ППФК НТУ «ХПІ»](http://polytechnic.poltava.ua)).

Керівник роботи – **Кожем'якін М. В.**.

## Завдання до дипломної роботи

Розробити веб-застосунок для кав'ярні, який дозволяє користувачам переглядати меню, оформлювати замовлення та використовувати систему знижок за допомогою дисконтної карти.
Реалізувати функціонал обліку клієнтів, застосування знижок та зручний інтерфейс для користувача.
